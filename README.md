# SaveWise CLI - Gerenciador Financeiro

Projeto desenvolvido para consolidar conceitos de Programação Orientada a Objetos (Java) e iniciar os estudos práticos em Banco de Dados Relacionais e padrão arquitetural DAO.

##  Tecnologias e Conceitos Utilizados
- Java (Versão 21)
- Banco de Dados Relacional (MySQL / PostgreSQL)
- Conexão via JDBC
- Arquitetura em Camadas + Padrão DAO
- Estruturas de repetição controladas para Menu (CLI)

##  Funcionalidades Planejadas
- [ ] Cadastro, listagem e remoção de transações (Receitas e Despesas).
- [ ] Exibição de saldo atualizado em tempo real.
- [ ] Filtro de transações por tipo ou categoria.
